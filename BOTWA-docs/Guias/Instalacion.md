# 📦 Instalación

## Requisitos

- Node.js 18 o superior
- npm

## Pasos

```bash
npm install
```

O usa:
```bash
instalar.bat
```

## Configurar las API Keys

Copia `.env.example` a `.env` y completa tus propias claves (Gemini, Unsplash, Google Search, Grok, OpenAI). El bot las lee automáticamente al iniciar; `config.json` ya no contiene secretos.

## Siguiente Paso

Ejecuta uno de los scripts:
- `iniciar-qr-normal.bat` - WhatsApp Normal con QR
- `iniciar-codigo-normal.bat` - WhatsApp Normal con Código
- `iniciar-qr-business.bat` - WhatsApp Business con QR
- `iniciar-codigo-business.bat` - WhatsApp Business con Código
