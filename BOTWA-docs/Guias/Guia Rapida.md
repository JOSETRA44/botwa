  WHATSAPP BOT - GUIA RAPIDA
═══════════════════════════════════════════════════════════

INSTALACION:
  npm install

INICIAR BOT:

  WhatsApp Normal (el comun):
    - Con QR:     iniciar-qr-normal.bat
    - Con Codigo: iniciar-codigo-normal.bat

  WhatsApp Business:
    - Con QR:     iniciar-qr-business.bat
    - Con Codigo: iniciar-codigo-business.bat

PANEL WEB:
  iniciar-panel.bat
  http://localhost:3000

CAMBIAR CUENTA:
  limpiar-auth.bat
  (Esto borra la sesion pero mantiene los archivos de codigo)

IMPORTANTE:
  La carpeta auth/ contiene:
  - loginQR.js y loginPhone.js (CODIGO - NO borrar)
  - creds.json, etc. (SESION - se puede borrar)
