## 📊 **Métricas de Diseño**

### **Espaciado**
- Padding cards: 24px
- Gap entre elementos: 16-24px
- Margin entre secciones: 24px

### **Tipografía**
- Títulos: 18-24px, peso 600-700
- Texto normal: 14px, peso 400
- Hints: 12px, peso 400

### **Bordes**
- Radio principal: 12px
- Radio botones: 8px
- Radio inputs: 8px

### **Sombras**
- Normal: 0 4px 6px rgba(0,0,0,0.1)
- Hover: 0 10px 15px rgba(0,0,0,0.1)
